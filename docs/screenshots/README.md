# Deployed dashboard screenshots

Native Chrome page screenshots captured from the user-supplied OCI Console dashboards on 12 November 2026. Images are unmodified page captures: browser tabs/address bar and DevTools are excluded by Chrome's screenshot command. No synthetic counts were substituted and no saved dashboard configuration was changed.

- `activity-dashboard.png`: Activity dashboard, with the provided global Last 124 days selection. The Console's global time range can override default windows in widget titles.
- `coverage-dashboard.png`: Coverage dashboard with the provided Last 60 minutes selection; includes summary tiles and the visible beginning of the covered/approaching-deadline tables.

These are dated deployment examples, not live health indicators or exhaustive full-dashboard exports. Screenshots include the deployment's visible compartment/resource identifiers; they contain no authentication credentials. README's corresponding Console links require existing OCI access and omit fixed screenshot times/Cloud Shell state. The architecture image above the showcase remains a separate design artifact.
