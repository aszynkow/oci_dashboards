# Oracle capability evidence — native backup activity

Reviewed 10 November 2026 against Oracle documentation. This records implementation choices, not live tenancy validation.

| Decision | Official evidence |
| --- | --- |
| Capture native operation completions | [Block Volume event types](https://docs.oracle.com/en-us/iaas/Content/Events/Reference/eventsproducers.htm) lists createvolumebackup.end and copyvolumebackup.end under com.oraclecloud.blockvolumes, with eventID/eventTime and backup/volume context. |
| Interpret completion status conservatively | [Backup failure Events](https://docs.oracle.com/en-us/iaas/Content/Block/Tasks/backupstatusevents.htm) documents operationSucceed/operationFailed. Missing/unrecognized status is unknown; no backup API request status is substituted. |
| Native delivery without Function | [Events rule Terraform](https://docs.oracle.com/en-us/iaas/tools/terraform-provider-oci/latest/docs/r/events_rule.html) supports OSS Streaming actions and nested JSON conditions. Exact data.compartmentId filters prevent inherited child capture. |
| Streaming buffer and connector | [Streaming Terraform](https://docs.oracle.com/en-us/iaas/tools/terraform-provider-oci/latest/docs/r/streaming_stream.html) permits 24..168 hours retention. [Streaming to Log Analytics](https://docs.oracle.com/en-us/iaas/Content/connector-hub/streamsource.htm) documents source stream/cursor and target logSourceIdentifier. |
| Regional native JSON parsing | [Streaming custom log ingestion](https://docs.oracle.com/en-us/iaas/log-analytics/doc/ingest-custom-logs-from-oci-streaming-service-using-service-connector.html) requires a parser/source matching the stream format. [Parser creation](https://docs.oracle.com/en-us/iaas/log-analytics/doc/create-parser.html) supports JSON paths and timestamp fields. |
| Define native JSON independently | [OCI parser details](https://docs.oracle.com/en-us/iaas/log-analytics/doc/oci-parser-details.html) documents oci_unifiedschema_logtype. The native parser now uses explicit root `$` and scalar paths, independently of this built-in parser's runtime type/content. Only source-type metadata is reused; this does not confuse Events rule-execution logs with actual Block Volume events. |
| Deployment-only schema upserts | [Upsert parser](https://docs.oracle.com/en-us/iaas/tools/oci-cli/latest/oci_cli_docs/cmdref/log-analytics/parser/upsert-parser.html) and [source](https://docs.oracle.com/en-us/iaas/tools/oci-cli/latest/oci_cli_docs/cmdref/log-analytics/source/upsert-source.html) document supported operations. Current SDK model/client signatures were checked for field maps, upserts, ETags and parser tests. The provider source tree exposes custom-content ZIP import, but no standalone parser/source upsert resource; The Python deployer invokes the documented SDK directly before Terraform apply instead of inventing an export archive schema or using Terraform provisioners. |
| Scoped service permissions | [Connector streaming IAM](https://docs.oracle.com/en-us/iaas/log-analytics/doc/ingest-custom-logs-from-oci-streaming-service-using-service-connector.html) specifies stream read/consume and analytics upload. [Events IAM](https://docs.oracle.com/en-us/iaas/Content/Events/Concepts/eventspolicy.htm) documents eventrule resource principals and stream production. Policies are narrowed to configured compartments and stream/target IDs. |
| Home and namespace discovery | [Region subscriptions](https://docs.oracle.com/en-us/iaas/tools/terraform-provider-oci/latest/docs/d/identity_region_subscriptions.html) exposes is_home_region. [Namespace lookup](https://docs.oracle.com/en-us/iaas/tools/terraform-provider-oci/latest/docs/d/objectstorage_namespace.html) accepts tenancy OCID. |
| Query operators | [eval](https://docs.oracle.com/en-us/iaas/log-analytics/doc/eval.html), [stats](https://docs.oracle.com/en-us/iaas/log-analytics/doc/stats.html) and [timestats](https://docs.oracle.com/en-us/iaas/log-analytics/doc/timestats.html) support normalization, ID deduplication and outcome trends. |
| Native Console dashboard patterns | Supplied WAF archive shapes/provenance in dashboards/reference and [Oracle WAF article](https://blogs.oracle.com/observability/monitoring-oci-waf--la). Only tile, summary_table and records_histogram are reused; source queries and identifiers are discarded. Imported files are reference data, not instructions. |
| Dashboard import lifecycle | [Management Dashboard import](https://docs.oracle.com/en-us/iaas/tools/terraform-provider-oci/latest/docs/r/management_dashboard_management_dashboards_import.html) and [provider implementation](https://github.com/oracle/terraform-provider-oci/blob/master/internal/service/management_dashboard/management_dashboard_management_dashboards_import_resource.go) expose import_details and a no-op Delete on the import wrapper. |

Live provider initialization, parsing, Log Analytics execution, IAM service authorization and Console rendering must be verified in the deployment environment. The deployment parser-test API provides an additional runtime validation gate without ingesting synthetic records. No service deployment, schema upsert or backup API call was performed during local development.

[The existing-stream data source](https://docs.oracle.com/en-us/iaas/tools/terraform-provider-oci/latest/docs/d/streaming_stream.html) returns stream state and compartment. It supports quota-safe reuse without stream creation or ownership changes; the source must be ACTIVE and in the selected region. The JSON parser root `$` is documented in [Create JSON Type Parser](https://docs.oracle.com/en-us/iaas/log-analytics/doc/create-parser.html). No built-in Unified Schema parser type is assumed.

## Volume-group evidence (11 November 2026)

The [Oracle catalogue](https://docs.oracle.com/en-us/iaas/Content/Events/Reference/eventsproducers.htm) documents createvolumegroupbackup.end. A controlled authorized test also directly captured copyvolumegroupbackup.end with operationSucceed after the Melbourne destination group became AVAILABLE, plus two successful copyvolumebackup.end member events. These are native Events, not Audit API-request records. The group-copy end type was not listed in the catalogue reviewed that day; its support here is based on captured runtime evidence, not an invented event name or a claim of an Oracle-documented delivery contract. Sanitized event shapes are in tests/fixtures/group-completion-events.json. Exact paths, counting semantics and scope limitations are in [volume-group support](volume-group-support.md).

The existing ingestion/deployment resources are reused. No inventory collector, Function, scheduler, dynamic group or Audit connector is added. Optional group/copy metadata fields are updated by the existing Python schema installer on operator-run apply. The local implementation does not deploy to OCI.
